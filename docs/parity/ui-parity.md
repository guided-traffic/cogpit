# UI parity: layout, navigation, tables, dock and feel

> **Target:** Lens Desktop 2026.10.51501

Cogpit's interface against Lens Desktop: the window's layout, clusters and hotbar, the navigator,
tables, the detail drawer, the dock with its editor, log and terminal tabs, the command palette,
menus, keyboard shortcuts, preferences and cluster settings. Resource views are in
[`resource-parity.md`](resource-parity.md), platforms and authentication in
[`platform-parity.md`](platform-parity.md), Cogpit's additions in [`beyond-lens.md`](beyond-lens.md)
and the method in [`README.md`](README.md).

**Sources:** Lens Desktop's documentation under
[Using Lens](https://docs.lenshq.io/k8slens/using-lens/layout/) (layout, navigator, hotbar,
details panel, log options, terminal, advanced editor, shortcuts, preferences, overview), its
cluster pages ([cluster settings](https://docs.lenshq.io/k8slens/cluster/cluster-settings/),
[metrics](https://docs.lenshq.io/k8slens/cluster/cluster-metrics/),
[create resource](https://docs.lenshq.io/k8slens/cluster/create-resource/),
[view logs](https://docs.lenshq.io/k8slens/cluster/view-logs/)) and its release notes to
2026.10.51501. Agents cannot run Lens Desktop (it needs an activated Lens ID): *captured* rows rest
on screenshots of an activated Lens Desktop, *capture needed* rows still need such a look
([D-12](../developer/decisions.md#d-12-parity-sources)).

**Plan:** *free* (Lens Desktop's Personal plan) or *paid* (Plus, Pro or Enterprise). Keys are
macOS's (⌘ ⌥ ⇧ ⌃); Windows and Linux use Ctrl and Alt. A row without evidence is missing.

**Summary (counted by `make parity`):** 128 of 133 rows exist: 120 of the 123
free-plan rows (112 partial, 8 done: the cell tooltip, right-click on a row, keyboard navigation in
tables and its shortcut row, the drawer's links with Forward…, the container port's link, the
forward dialog and the terminal's scrollback) and 8 of the 10 paid rows (the hotbar's six, the diff
view and the Ask AI shortcut, which opens Cogpit's agent chat; all partial). Missing: Reload,
untrusted certificate authorities for non-cluster traffic, several windows, and the paid Lens CLI
and Cost rows. 12 more rows are not a target, among them pasting a kubeconfig
([D-21](../developer/decisions.md#d-21-pasting-a-kubeconfig)), the hotbar's banks
([D-83](../developer/decisions.md#d-83-one-hotbar-and-a-drag-that-carries-the-tile)), Lens Metrics
([D-61](../developer/decisions.md#d-61-cogpit-metrics-the-bundled-metrics-stack)) and the cloud
integrations ([D-9](../developer/decisions.md#d-9-scope-against-lenss-paid-and-vendor-features)).
Open work: [G5](gaps.md#g5-app-shell-navigation-tables-and-drawer) (layout, navigator, tables,
drawer, dock), [G13](gaps.md#g13-clusters-hotbar-palette-menus-shortcuts-and-preferences) (clusters,
hotbar, palette, menus, shortcuts, preferences, cluster settings),
[G8](gaps.md#g8-logs-terminal-and-shells) (logs, terminal, shells) and
[G9](gaps.md#g9-yaml-editor-and-create-resource) (editor, create resource).
